## How it works

"8 Inputs are given using 8 switches. If any one of the switch is ON, the 7 segment display shows number 1. If more than 1 switch are ON, a counter is called
displaying numbers 2 to 8 and at the end displays the first letter of my name "A". Clicking the reset button would allow user to display all those panels of 7 segment, the corresponding switches of which are turned ON."

## How to test
"Powering ON the Board would display number 0 on the 7 segment display. Switching ON any one of the switch on the board would display number 1 on the 7 segment.
If more than one switch is ON, then a counter should start going from 2 to 8. Holding the reset button would display only those panels whose corresponding switch 
is turned ON"
